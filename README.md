# NutriTrack — Calorie & Macro Tracker

A fast, clean, and modern calorie and macro tracking web application built with pure vanilla HTML, CSS, and JavaScript.

## Features
- **Daily Dashboard**: Real-time calorie budget breakdown (Consumed, Target, Remaining).
- **Dynamic Visual Status**: Interactive calorie progress bar and macro meters for Protein, Carbs, and Fats.
- **Date Navigation**: Easily view and log intake for past, present, or future dates.
- **Hydration Tracker**: Interactive visual water counter with glass-by-glass tracking.
- **Quick-Add Presets**: Instant one-click logging for popular food items.
- **Categorized Food Log**: Organized by Breakfast, Lunch, Dinner, and Snacks with individual macro breakdowns and timestamps.
- **Search & Filtering**: Live search your logged meals.
- **Custom Goals**: Adjust daily calorie, macro, and water targets anytime with instant recalculation.
- **100% Client-Side**: Persistent storage using browser `localStorage` — no backend required and zero tracking.
- **Pure Vanilla Stack**: Built without frameworks, Tailwind, or CSS variables.

## How to Run
Simply open `index.html` in any web browser.
